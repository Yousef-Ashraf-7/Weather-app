# Weather App

A simple weather application built using HTML, CSS, and JavaScript.

## Features

* Search for a city and check its current weather.
* Display weather information using a weather API.
* Simple and responsive user interface.
* Practice working with APIs and JavaScript.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Weather API

## How to Use

1. Open the application.
2. Enter the name of a city.
3. View the weather information for that city.

## Project Purpose

This project was created to practice front-end development, JavaScript, and working with APIs.
